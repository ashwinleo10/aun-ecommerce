# AÚN — Clothing E-Commerce Platform

A unisex clothing e-commerce platform built with **React** and **Spring Boot**, featuring secure authentication, product management, shopping cart, wishlist, order management, Razorpay payments, Cloudinary image storage, and separate customer/admin experiences.

## Live Demo

**Frontend:** https://aun-frontend.vercel.app/

**Backend:** Deployed on Render

---

## About the Project

**AÚN** is a modern clothing e-commerce application designed to provide a complete online shopping experience for customers while providing administrators with tools to manage products, categories, customers, orders, inventory, and payments.

The application follows a full-stack architecture with a React frontend communicating with a Spring Boot REST API backed by MySQL.

---

## Features

### Customer Features

- User registration and login
- JWT-based authentication
- Secure HttpOnly cookie authentication
- Customer and admin role-based access
- Browse products and categories
- Product details with size and color selection
- Add products to cart
- Update cart quantities
- Remove cart items
- Wishlist management
- Product stock validation
- Address management
- Checkout
- Cash on Delivery (COD)
- Online payment using Razorpay
- Order history
- Order details
- Order cancellation where applicable
- Automatic stock management
- Responsive customer interface

### Admin Features

- Admin authentication and authorization
- Admin dashboard
- Category management
- Product management
- Product image upload
- Customer management
- Customer details
- Order management
- Order status updates
- Payment status management
- Inventory/stock management
- COD payment confirmation
- Protected admin routes

### Payment Features

- Razorpay payment integration
- Razorpay order creation
- Payment verification
- Payment failure handling
- Payment webhook processing
- Duplicate webhook protection
- Online payment status tracking
- COD payment workflow
- Stock restoration for eligible cancelled orders
